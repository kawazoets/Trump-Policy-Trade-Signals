# 2025年7月23日のAI Action Planと同日のAI関連株購入

**2025年7月23日のAI Action Planと同日のAI関連株購入**を調べます。

Case 01とは性質が違います。

### Case 02で何を見るのか

2025年7月23日、ホワイトハウスはトランプ政権の大きなAI政策である **“America’s AI Action Plan”** を公表しました。
同じ7月23日に、トランプ氏の投資口座ではAI・Big Techに関係する複数企業の株式購入が報告されています。

現在候補になっているのが、
- Nvidia
- Broadcom
- Microsoft
- Amazon
- Apple
- Meta
です。

報道ベースでは、それぞれ**100万～500万ドルのレンジ**の購入とされています。
つまり単純化すると、

> **July 23, 2025**  
> AI関連6社を購入  
> ↓  
> **July 23, 2025**  
> White HouseがAI Action Planを発表
です。

Case 01は「前日に327件購入 → 翌日に政策変更」でした。

Case 02は**「取引日＝政策発表日」**です。
ここには非常に重要な違いがあります。
### 同日だからこそ、簡単には「怪しい」と言えない

OGEの開示では通常、**日付は分かっても取引時刻までは分かりません**。
仮にAI Action Planが午前9時に公開され、株式購入が午後2時なら、公開情報を見て購入した可能性があります。
逆に午前9時発表で、午前8時に購入していたなら意味が違ってきます。
しかしOGEだけではそこまで分からない。

したがってCase 02の最初の判定は、
**Temporal Gap = 0 days**
であって、
**Trade Before Policy = Unknown**
です。

### さらに重要なのが「AI Action Planは本当にサプライズだったのか」も調べなければいけません。

実はトランプ政権がAI Action Planを策定すること自体は、突然7月23日に決まったわけではありません。
2025年1月23日にトランプ氏はAIに関するExecutive Orderを出し、**180日以内にAI Action Planを策定するよう指示**していました。

したがって、
> 7月23日にAI株を買った  
> ↓  
> その日に突然AI政策が発表された
という単純な構図ではありません。

**AI政策が7月頃に出てくること自体は、かなり前から公知だった可能性があります。**

これはCase 02で必ず入れるべき反証材料です。

### では、何が調査対象になるのか

単に「AI Action Planが出ることを知っていたか」では弱い。
見るべきなのは、**最終的な政策内容が特定企業に有利だったのか**です。

たとえばNvidiaなら、
AIチップ輸出政策  
→ データセンター建設  
→ AIインフラ輸出  
→ 半導体政策

Broadcomなら、
AI accelerator / networking  
→ データセンター  
→ 半導体政策

Microsoft・Amazonなら、
AI data centers  
→ cloud infrastructure  
→ federal AI adoption

という接続があります。

つまり、
**「AI政策発表日にAI株を買った」**
だけではなく、
**「その日に買われた企業群と、同日発表された政策内容にはどの程度具体的な経済的接続があったのか」**
まで見る必要があります。

### そして、もう一つ非常に重要な検証

**その日、AI関連6社“だけ”を買ったのか？**

たとえば7月23日に、
```
Nvidia
Broadcom
Microsoft
Amazon
Apple
Meta
```
だけを買っていたなら、かなり目立つパターンです。

しかし実際には、
```
AI stocks      6
Banks         25
Industrials   40
Healthcare    30
Consumer      35
...
Total        250 purchases
```

だったとすれば意味は大きく変わります。
これはCase 01で出てきた**direct indexing / automated portfolio management**という代替説明ともつながります。

だからCase 02では、6社だけを抜き出して終わってはいけなく
**2025年7月23日の全取引**
を確認する必要があります。

### Case 02の検証項目
1. OGE原本から7月23日の全取引を抽出
2. Nvidia / Broadcom / Microsoft / Amazon / Apple / Metaの取引を一次確認
3. それぞれの正確な金額レンジを確認
4. Purchase / Saleを確認
5. 同日の総取引件数を確認
6. AI関連企業が全体の何％だったか確認
7. AI Action Planの公式公開時刻・内容を確認
8. 1月23日のExecutive Orderとの関係を確認
9. 政策が各企業に具体的にどう接続するか確認
10. 「通常のportfolio strategy」という代替説明と比較

Case 01とCase 02が揃うと、すでに比較ができます。

**Case 01**  
327 purchases → **翌日** tariff reversal

**Case 02**  
AI-related purchases → **同日** AI Action Plan

ただし、どちらにもautomated portfolio managementという代替説明が存在する。
この「一見かなり目立つ時系列なのに、調べるほど簡単には結論を出せなくなる」というところが、このプロジェクトのかなり重要な部分になってきています。

では次に、**OGE原本から2025年7月23日の全取引を抽出して、Case 02を実データ化**しましょう。
Case 02はかなり重要なところまで一次資料で確認できました。

**ここで、最初の見え方を少し修正する必要があります。**

結論からいうと、2025年7月23日は「AI関連6社だけを買った日」ではありません。
OGE年次開示を確認すると、この日は **Investment Account #6で合計279件の取引**があり、
その内訳は**251件のPurchase、28件のSale**でした。

ただし、その中に非常に興味深い特徴はあります。
### 6社は「多数の買いの一部」だが、金額帯では最上位

7月23日の251件のPurchaseを金額レンジ別に見ると、次のようになります。

| Amount RangePurchase件数 | |

| $1,001–$15,000 | 3 |

| **$1,000,001–$5,000,000** | **6** |

そして、**最高額レンジの6件がちょうど以下の6社です。**

| OGE #CompanyTransactionDateAmount | | | | |
| --------------------------------- | -------------- | -------- | ---------- | --------------------- |
| 1312 | Broadcom | Purchase | 2025-07-23 | $1,000,001–$5,000,000 |

これはOGE原本で直接確認できます。

つまり、最初の
> 「AI関連6社を同日に買った」
だけでは少しミスリーディングでした。
より正確には、
> **7月23日には251銘柄を購入していた。しかし、その日の最大購入額レンジに入った6社は、Broadcom、Meta、Amazon、Apple、Microsoft、Nvidiaだった。**
ということです。

研究テーマとしては面白くなります。

### AI関連以外も大量に買っている

たとえば同日には、Intel、AMD、Applied Materials、Micron、NXP、Lam Research、Palantirだけでなく、Boeing、Pfizer、Chevron、Disney、Coca-Cola、Walmart、JPMorganなども購入されています。
また28件のSaleもあり、Berkshire Hathaway、Costco、McDonald's、Equinix、Super Micro Computerなどが売却されています。

したがって、
**「AI Action Planの日にAI株だけを狙って買った」**
とは言えません。

これは重要な反証材料です。
一方で、
**「251件という広範な買いの中で、最大金額レンジの6件がすべてAIの主要プレイヤーだった」**
という事実は残ります。

ここがCase 02の本当の論点になりそうです。
### 政策側も一次確認できました
ホワイトハウスは2025年7月23日に正式に **“Winning the AI Race: America’s AI Action Plan”** を公開しました。

90以上の政策措置を、
- Accelerating Innovation
- Building American AI Infrastructure
- Leading in International Diplomacy and Security

の3本柱で整理しています。
特に、米国企業のハードウェア、モデル、ソフトウェアなどを組み合わせた「full-stack AI export packages」の海外展開も政策に含まれています。
これはNvidiaやBroadcomのような半導体企業だけでなく、Microsoft、Amazon、MetaなどAIインフラ・モデル・クラウド企業にも経済的に接続し得る内容です。

ただし重要な反証があります。
トランプ氏は**2025年1月23日のExecutive OrderですでにAI Action Planの策定を命じていました**。
ホワイトハウスは関係当局に180日以内の計画策定を指示していました。したがって、夏ごろに大規模AI政策が出ること自体は秘密ではありませんでした。
さらにOGEには取引**時刻**がありません。
したがって、
> 7月23日午前：株購入  
> → 午後：政策発表
だったのか、
> 午前：政策発表  
> → 午後：株購入

だったのかは、現在の公開資料からは確定できません。
